# Week 06 · Team 06 — Pipeline Explorer

موقع يرفع ملفات المشروع ويعرض، خطوة بخطوة، وش يسوي النوتبوك فيها ووين تروح البيانات.

- **أكواد النوتبوك** (EX01–EX10 + بونص SQL): تشتغل كما هي من ملف `.ipynb` نفسه.
- **أكواد البرنامج** (AI-1 إلى AI-4): مشروع كشف الشذوذ، وهي آخر خلايا نفس النوتبوك.

## التشغيل (يحتاج Python 3.10 أو أحدث فقط)

على Windows: دبل كليك على `run.bat`. أول مرة يثبّت المكتبات ثم يفتح المتصفح على `http://localhost:8000`.

أو يدوياً:

```
pip install -r requirements.txt
python run.py
```

بعدها ارفع `week_06_team_project_data_S000.zip` (أو الملفات الأربعة اللي داخله) واضغط **Run the pipeline**.

## وش في الموقع

| التبويب | وش يعرض |
|---|---|
| Step by step | مشهد متحرك لكل خطوة (شاحنة توصّل الملف، آلة تفتح الكرتون، فرز الصفوف في صناديق...)، ومعه وش قرأت، أي دالة اشتغلت، وش كتبت، الجداول والتحققات، وكود الدالة من النوتبوك. سرعة الحركة تتغير من قائمة Animation |
| AI project | فكرة مشروع الذكاء الاصطناعي ونتيجته: القاعدة الثابتة مقابل الـ baseline مقابل النموذج |
| Data flow | مخطط يبيّن كل صف خام وين انتهى: مقبول (وأي منطقة)، مرفوض (وليش)، أو مكرر |
| Trace a row | تختار أي صف وتشوف كل دالة مرّ عليها ووين وقف |
| Outputs | تحميل المخرجات: الثمانية الإلزامية، بونص SQL، ومخرجات مشروع الذكاء الاصطناعي |

## كيف تشتغل أكواد النوتبوك بدون تغيير

`backend/notebook_loader.py` يقرأ `backend/notebook/Week06_Team06_With_AI_Project.ipynb` ويأخذ من كل خلية: الـ imports والدوال والثوابت فقط، ويتجاوز الأسطر الخاصة بـ Colab (ربط Drive، واستدعاءات العرض). بعدها `backend/runner.py` ينادي نفس الدوال بالترتيب على الملفات المرفوعة. ما فيه أي دالة تحليل مكتوبة مرتين.

يعني لو عدّلتوا دالة في النوتبوك واستبدلتوا الملف في `backend/notebook/`، الموقع يشغّل النسخة الجديدة مباشرة.

## هيكل المشروع

```
run.py / run.bat        تشغيل الموقع
requirements.txt        مكتبات Python
backend/
  app.py                FastAPI: الرفع، حالة التشغيل، الملفات
  notebook_loader.py    يحمّل دوال النوتبوك كما هي
  runner.py             ينفذ الخطوات ويسجل مدخلات ومخرجات كل خطوة
  notebook/             النوتبوك (نفس الملف اللي يشتغل في Colab)
frontend/
  src/                  كود React
  dist/                 النسخة المبنية اللي يخدمها Python (ما تحتاج Node للتشغيل)
runs/                   يُنشأ عند التشغيل: مدخلات ومخرجات كل تشغيلة
```

## تعديل الواجهة (اختياري، يحتاج Node.js)

```
cd frontend
npm install
npm run dev      # للتطوير على http://localhost:5173 والخلفية شغالة على 8000
npm run build    # يحدّث dist
```
